# Mi Ecommerce Sprint 1

Aplicación web monolítica educativa construida con Node.js, Express.js, EJS, HTML5 semántico y CSS3.

## Requisitos implementados

- Server Side Rendering con Express y EJS.
- Rutas: `/`, `/products`, `/cart`, `/checkout`, `/login` y `/register`.
- Vistas separadas en `views/pages`.
- Parciales reutilizables en `views/partials`.
- Archivos estáticos en `public/css` y `public/images`.
- Navegación entre Home, Product, Cart, Checkout, Login y Register.
- Diseño responsive para desktop y mobile con Flexbox, CSS Grid y media queries.

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm start
```

Luego abrir:

```text
http://localhost:3000
```

## Validación

```bash
npm test
```
